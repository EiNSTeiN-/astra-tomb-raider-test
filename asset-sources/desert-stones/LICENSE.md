# Rock Moss Set 01: desert geometry derivative

[Rock Moss Set 01 by Kless Gyzen](https://polyhaven.com/a/rock_moss_set_01)
is distributed by Poly Haven under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/), as
recorded on the [Poly Haven asset license page](https://polyhaven.com/license).

The desert delivery file derives from this project's existing simplified scan.
Its six meshes retain positions, normals, indices and node transforms. Original
materials, texture images, UVs and tangents are omitted. The game applies the
separately credited Sandstone Cracks maps and original terrain-placement code.
Small rubble geometry is original project code.

`sources.json` records the exact input and output hashes. Reproduce the
derivative with `node scripts/build-desert-stones.mjs` from the checked-in source
GLB. No raw external download is needed for this conversion.
