# Fir sprig derivatives

The model geometry and source color texture are from
[Poly Haven — Fir Tree 01](https://polyhaven.com/a/fir_tree_01), released under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
Poly Haven's asset license is described at <https://polyhaven.com/license>.

The delivered meshes and `fir-sprigs-color.png` / `fir-sprigs-normal.png`
are derivatives of that existing source. The original needles are projected
into cutout textures; their positions and normals define the baked geometry
and normal maps. The conversion code is original project code.

Input/output hashes and reconstruction parameters are in `sources.json`.
Downloaded sources and conversion intermediates are excluded from publication.
